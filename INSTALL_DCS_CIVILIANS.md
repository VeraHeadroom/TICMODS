# TIC_Civilians (DCS World)

Unarmed civilian people for DCS World: men in a thobe, a keffiyeh or a shirt, a woman, an old man and a child, on DCS's
own human chassis and infantry animations (they walk, run, fall). Nothing runs by itself: they appear only when a
mission or a server places them (unit types `TIC_Civ_Man_01`, `TIC_Civ_Man_Keffiyeh_01`, `TIC_Civ_Man_Shirt_01`,
`TIC_Civ_Woman_01`, `TIC_Civ_Elder_01`, `TIC_Civ_Child_01`, ...). 2026-11-11.

## Install (every player who should see them, and the server)

1. Close DCS. Unzip this package. Copy `Mods/tech/TIC_Civilians` into your DCS Saved Games folder's `Mods\tech\`
   (`Saved Games\DCS\Mods\tech\TIC_Civilians`, or `DCS.openbeta`; a dedicated server:
   `Saved Games\DCS.server\Mods\tech\TIC_Civilians`; make the folders if they are not there).
2. Start DCS. Check: `Saved Games\DCS\Logs\dcs.log` has no `tic_civ_` errors.
3. Remove it by deleting that folder.

Without the mod you see the server's civilians as another unit, not as these people.
