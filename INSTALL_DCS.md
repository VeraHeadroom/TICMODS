# TIC_FastSoldier (DCS World)

Unit types for DCS World: soldiers on DCS's own soldier models that run up to 6 m/s (DCS's own top out at 4), and a few
faster ground vehicles. Nothing runs by itself: they appear only when a mission places them. 2026-11-07.

## Install

1. Unzip this package. Copy `Mods/tech/TIC_FastSoldier` into your DCS Saved Games folder's `Mods\tech\`
   (`Saved Games\DCS\Mods\tech\`, or `DCS.openbeta`; make the folders if they are not there).
2. Restart DCS. Remove it by deleting that folder.
